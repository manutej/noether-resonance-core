1 · Why "Tab Audio" Prompts to Share a Window & How to Capture System Audio Cleanly

Web browsers restrict silent desktop audio capture for security: getDisplayMedia() is the only browser API that can tap another browser tab's audio, which forces Chrome/macOS to show a "Share tab/window" picker.
For zero-popup system audio at the Summit: Use 🎙 Talk to Noether (for voice) or select a virtual loopback driver such as BlackHole 2ch / Loopback inside Studio Controls → Card IV → Audio Input. That uses getUserMedia() directly with zero window-share prompts.
